Text replacement on a Mac: set it up, fix it, and know where it stops

By Cyanote · 23 November 2026 · 11 min read
  • macOS
  • How-to
  • Buying advice

Text replacement is the text expander built into your Mac. Open System Settings → Keyboard → Text Replacements, click the Add button and enter a shortcut and its replacement. Type the shortcut, then a space or punctuation, and macOS swaps it in. It's free and can sync to your iPhone. If it doesn't work, look first at Edit → Substitutions → Text Replacement in the app you're using.

I make Cyanote, which keeps pinned snippets but doesn't expand abbreviations, so it doesn't compete with most of what's below. Everything here about other software comes from the pages I link, read on 23 November 2026, not from side-by-side testing.

The short version

  • Set it up: System Settings → Keyboard → Text Replacements. The steps are the same on macOS 26 and 27.
  • Stopped working in one app: tick Edit → Substitutions → Text Replacement there.
  • Word and Pages keep lists of their own. Word doesn't use the Mac's list in the body of a document.
  • Chrome and Firefox do support it now. Guides that say otherwise are out of date.
  • Back it up by dragging the entries to the desktop, and keep that file before you import anything.
  • Switch to a text expander when you need dates, fill-in fields or hundreds of entries. Espanso and Raycast's free plan cover those without paying.

How to set up text replacement on a Mac

Apple's guide to replacing text gives the route:

  1. Choose Apple menu → System Settings, then Keyboard in the sidebar.
  2. Click Text Replacements.
  3. Click the Add button. Type the shortcut, then its replacement.
  4. Click Add, then Done.

In many apps there's a quicker way in: Edit → Substitutions → Show Substitutions, then Text Settings.

The swap happens when the shortcut is followed by a space or a punctuation character, as TidBITS explains. So choose shortcuts you'd never type as words. addr is asking for trouble and ;addr isn't. MacMost's tutorial suggests starting them with an exclamation mark for the same reason.

Several lines. Apple's page doesn't mention line breaks. MacMost says you can press Option + Return for a new line while typing the replacement, or paste in text that already has several lines.

How long. MacMost says any length, even several paragraphs. A user on Apple's forum reported in 2023 that there "seems to be a 2,000 character limit", in a thread now readable only as an archived copy. Apple documents neither, so test a long one before you depend on it.

What not to put in it. Leave out passwords, card numbers and recovery codes. The list exports to a file that Apple says you can edit in TextEdit, so treat everything in it as readable.

Sync it to your iPhone, and back it up

Apple's backup page says iCloud keeps the list the same on your devices. You set up iCloud Drive on each one and sign in to the same Apple Account. After that, an entry added on the Mac "automatically works on your other devices (and vice versa)".

Sync isn't a backup. If an entry is deleted on one device, expect it to go from the others. The same page documents a proper copy:

  • To export: in the Text Replacements window, select the entries you want, or Edit → Select All, and drag them to the desktop. You get a file called property list.plist.
  • To import: drag that file into the Text Replacements window on the other Mac and click Done.

Export before you import. In May 2026, TidBITS's Adam Engst tried to import a list of more than 2,700 corrections. He got an unhelpful error about too many entries, and sometimes the whole list came back empty. He never found where "too many" begins. A few dozen entries is a much safer size than a few thousand.

Browsers. You'll still read that Chrome ignores your replacements. The Substitutions menu is in Chromium's code, and a February 2026 Firefox bug report says Safari and Chrome expand them "in all input field types except password." Firefox got there later. Its text substitution work landed in version 130 but stayed switched off until support for the autocorrect attribute was on by default.

That attribute is why one website works and the next doesn't. A page can set autocorrect to off on a field, and Chromium's code then allows no substitutions there. You can't change that from System Settings.

Word. Two people in the TidBITS discussion describe it well: one is annoyed that Word doesn't use the Mac's entries, and another finds that they expand in comments but not in the main text.

Obsidian. In 2020 users reported that nothing happened, and the bug was set aside as coming from Electron. A user in the feature request suggested the built-in list as a workaround in March 2025, which implies it works for some. In July 2026 another published a community plugin to add it, and says they aren't a developer and built it with an AI tool. Weigh that before installing it.

Text replacement not working? Fix it in this order

Start with a control. Type one of your shortcuts in TextEdit, followed by a space.

If it works in TextEdit, the list is fine and the app is the problem:

  1. Tick the menu item. Choose Edit → Substitutions and make sure Text Replacement has a tick. TidBITS's February 2025 tip found this had switched itself off, for reasons nobody could explain, and that turning it off and on again may help even when it looks right. It costs nothing to try.
  2. Check whether the app has its own list. If it's Word, Pages or Google Docs, add the entry there as well.
  3. Try another field or site. If it only fails in one web form, the page has probably turned it off.
  4. Quit and reopen the app, then restart the Mac. One TidBITS commenter says a restart fixed it in Safari and FileMaker when the menu hadn't.

If it fails in TextEdit too:

  1. Check the trigger. Type a space after it. Look at Text Replacements and confirm it's spelt as you think.
  2. Delete the entry and add it again. A commenter on MacMost's tutorial found that edited entries kept producing the old text until they did this.
  3. Quit other expanders. Raycast, for one, skips its own keywords when they clash with the Mac's, "to avoid double insertion", unless you tell it otherwise. Don't define the same shortcut in two places.
  4. Check sync last. If entries are missing on one device only, confirm iCloud Drive and the Apple Account on both. Export the list first. Some old fixes involve signing out of iCloud or deleting its stored data, and I wouldn't try those without a copy.

If your expander is the thing that's dead, and everywhere at once, the cause may be Secure Input. I cover that in copy and paste not working on a Mac.

Questions people ask

Is there a free text expander for Mac?

Yes, several. The built-in one is included, Espanso is free and open source, and snippets are part of Raycast's free plan. TextExpander's free plan holds five active snippets.

Can text replacement insert today's date?

Not the Mac's own. It inserts the same text each time. Espanso, Raycast, Alfred, Typinator and TextExpander all document date placeholders.

How do I turn text replacement off?

In one app, untick Edit → Substitutions → Text Replacement. To stop a single shortcut everywhere, remove it in System Settings → Keyboard → Text Replacements.

Why does it leave an extra space?

Because the space you typed to trigger it stays. MacMost suggests clicking the suggestion that appears, or pressing Down Arrow and Return, which inserts the text without it.
