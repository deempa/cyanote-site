Calendar not syncing between iPhone and Mac: a two-minute test

By Cyanote · 23 November 2026 · 12 min read
  • Calendar
  • macOS
  • How-to

If your calendar isn't syncing between your iPhone and Mac, first check that both use the same account. Find out which calendar one missing event belongs to, then look for that event on the account's website. If it isn't there, the device you made it on never sent it. If it is, the other device isn't fetching that account, or it's hiding the calendar. Work calendars from Microsoft have an extra cause that began in October 2026.

Your devices don't talk to each other. Each talks to iCloud, Google or Microsoft, so a fault sits on one side of that middle point or the other. The paths below are from Apple's macOS 27 and iOS 27 guides, read on 23 November 2026. The Mac settings I compared with the macOS 26 guide have the same names. I haven't reproduced these faults; this is what Apple, Google and Microsoft document.

The short version

  • Read the event's calendar. iPhone: tap the event and look at Calendar. Mac: double-click it and look at the menu in the top-right corner.
  • Check the website. iCloud.com's calendar, Google Calendar or Outlook on the web shows what the account really holds.
  • Made on the iPhone and not on the website? Fix the iPhone's default calendar or its iCloud switch.
  • On the website but not the Mac? Add the account, tick the calendar, turn off any Focus filter, refresh.
  • Work Microsoft account, fine on the phone? It may be the Exchange shutdown, and your IT department has to act.
  • Export before you remove anything. Use .ics files. Restoring a full calendar archive replaces everything you have.

The "which calendar is it in?" test

Apple's calendar apps pour several accounts into one grid, so two devices can look alike while showing different things. This test ignores the grid.

  1. On the iPhone, add an event called sync test for tomorrow.
  2. Tap it, then read the name beside Calendar. Tap that to see which account it sits under.
  3. Open that account's website. For iCloud, Apple says you need a tablet or a computer. If the site won't show your data, web access may be turned off, which happens automatically with Advanced Data Protection.
  4. On the Mac, choose View → Show Calendar List and tick every calendar, then View → Refresh Calendars. Search for "sync test".

Wherever the event stops is the leg to fix. Delete the test when you're done.

Before you change anything, spend ten seconds on Apple's System Status page, which lists iCloud Calendar separately. It covers iCloud only, not Google or Microsoft.

The event never reached the website

It was saved to the wrong calendar. New events go to the default calendar. On the iPhone, set it in Settings → Apps → Calendar → Default Calendar. On the Mac, it's in Calendar → Settings → General. Changing it doesn't move existing events. On the iPhone, move those one at a time with the Calendar field you just read.

iCloud Calendar is off on the phone. The path is Settings → your name → iCloud → See All → iCloud Calendar, then Use on this iPhone.

The account's calendar is off. For Google or Microsoft, go to Settings → Apps → Calendar → Calendar Accounts, tap the account and make sure calendars are on.

You made it on the Mac, under On My Mac. This is the reverse direction. Calendars in that section aren't in any account, so no phone will see them. Apple's route is to export the calendar to an .ics file and import it into an iCloud calendar.

It's on the website but not on the Mac

Start with View → Refresh Calendars. If that brings the event in, the Mac was just slow, and the table further down shows what decides how slow. If not, check these in order. The first three come from Apple's page on missing events.

  1. The calendar is unticked in the calendar list.
  2. iCloud Calendar is off on the Mac. Check that Calendars is on in System Settings → your name → iCloud → See All. If the account is Google or Microsoft, look in Calendar → Settings → Accounts, and use Calendar → Add Account if it isn't there.
  3. It's hidden by type. Make sure Show All-Day Events is ticked in the View menu. If you declined it, turn on Show Declined Events.
  4. A Focus is filtering calendars. Focus filters can choose which calendars appear. If the calendar vanishes at work hours, look in System Settings → Focus.
  5. A warning symbol beside the name. Apple says Calendar can't connect to that calendar's account.

Google Calendar not syncing with Mac Calendar

If your own Google calendar arrives and a shared or family one doesn't, check which calendars Google sends. Google's help page says it automatically syncs everything under My Calendars, plus birthdays. Anything else has to be ticked on the calendar sync page, opened on a computer and signed in to the right account. Tick it, Save, then refresh Calendar on the Mac.

Google adds that if you used to reach calendars through Delegation in Apple Calendar, you have to untick them there for this to work. The setting is in Calendar → Settings → Accounts → Delegation.

Outlook calendar on the iPhone but not on the Mac

For a work or school account, this is the first thing to rule out. The same account uses a different route on each device.

Microsoft began turning off Exchange Web Services in its cloud service (Microsoft 365 and Exchange Online) on 1 October 2026. It names Apple Mail and Calendar on macOS among the affected apps, and lists repeated password prompts as one symptom. It's going organisation by organisation, so a colleague elsewhere may still be fine, and anyone whose IT team opted to keep the service on isn't cut off yet. Mailboxes on a company's own Exchange server aren't part of this. iPhones use Exchange ActiveSync and aren't affected, MacRumors reports.

The fix is on the server, so only your administrator can make it. Send them Apple's support page, which says what to enable. That lasts until 1 April 2027, when Microsoft shuts the service for good. Apple says it's moving its apps to Microsoft's newer system "in a future update to macOS 27", and the 27.2 release notes don't mention it. Microsoft's current Outlook for Mac works in the meantime. The legacy version doesn't, because it uses the same service.

For a personal Outlook.com calendar, Microsoft documents adding it on the iPhone. I couldn't find a current page from Microsoft or Apple for adding one to the Mac's Calendar. The documented fallback is to publish it and subscribe to the ICS link. That's read-only, and publishing lets anyone with the link see it.

A subscribed calendar isn't updating

School terms, sports fixtures and shared rotas are usually subscriptions, and they follow their own rules.

Where it lives. On the Mac, choose File → New Calendar Subscription, then Location. iCloud puts it on all your devices. On My Mac keeps it on that computer. If it's only on the Mac, control-click it, choose Get Info and copy the address. Then unsubscribe and add it again with Location set to iCloud.

How often it checks. The same Get Info window has an Auto-refresh menu on the Mac. The publisher controls what comes back, so if the event isn't in the publisher's feed yet, refreshing can't help. You can't edit one either, and the same goes for a shared calendar marked View Only.

None of those Apple pages gives a default interval, so look at your own menu. The iPhone row is easy to miss: on that setting, a phone in your pocket all day may not pick up a change until you plug it in or refresh it by hand.

Old events missing, wrong times, duplicates

Past events are missing on the iPhone. Look at Settings → Apps → Calendar → Sync. It can be limited to a set period. Apple's fix is to switch it, from All Events to a period or the other way, wait a few minutes, then swipe down on the calendars list to refresh.

The event is there, at the wrong time. The iPhone's Time Zone Override shows everything in one fixed zone. The Mac's version is Turn on time zone support in Settings → Advanced, plus a menu in the toolbar. If only one device has it set, every event looks moved. On the Mac, an event set to Floating keeps its time in any zone.

Everything appears twice. Check whether the same calendar is on the device by two routes, such as a signed-in Google account plus a subscription to that calendar's secret address. Two sets of birthdays are normal: Google adds its own Birthdays calendar. Hide one by unticking it rather than deleting events. Deleting from a synced account deletes everywhere.

The event is right and the alert never came. That isn't sync. Check System Settings → Notifications → Calendar. Apple's 27.2 notes list a known issue where a clean install might never ask for permission. Turning notifications on there by hand is Apple's workaround.

Before you remove an account or sign out

An event that never left one device can go with the account, so copy things out before you start.

  • Export first. Select a calendar and use File → Export → Export for an .ics file. Be careful with Calendar Archive (.icbu): Apple warns that importing one "replaces all of your current calendar information."
  • Prefer switching off to deleting. With iCloud Calendar off, Apple says you simply won't see iCloud calendars on that Mac. For any account, in Calendar → Accounts, deselecting Calendar hides the account, and its events reappear when you select it again.
  • Deleting can spread. With iCloud Keychain on, removing an account other than iCloud asks whether to remove it from your other Macs too.
  • Signing out of iCloud asks whether to keep copies of Calendar data on the Mac. Copies you keep stop updating.
  • Restoring on iCloud.com rolls back calendars and reminders together and removes all sharing. Apple archives your current version first, so you can go back.

You'll know it's fixed when a new event made on each device appears on the other, and a change of time follows it. Check both directions.

Questions people ask

Would a different calendar app fix it?

Only if Apple's app is the broken leg. For a Microsoft work account, the current Outlook for Mac doesn't depend on the service being shut down. For anything missing on the provider's website, no app can show it. If you're choosing one for other reasons, I looked at whether Fantastical is worth it.

Do my reminders sync the same way?

They can appear in Calendar, but they have their own iCloud switch and their own faults. See reminders not syncing between iPhone and Mac. Notes are separate again, and I cover those in Apple Notes not syncing.

Is there a limit on how much iCloud Calendar can hold?

Yes. Apple lists 50,000 calendars, events and reminders in total and up to 100 calendars and reminder lists combined, though updated reminders don't count towards either. An event can be up to 20 MB with its attachments.
