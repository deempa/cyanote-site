How to export Apple Notes: PDF, Markdown, Word, and all of them at once

By Cyanote · 23 November 2026 · 10 min read
  • Notes
  • macOS
  • How-to
  • Backups

To export an Apple note on a Mac, select it and choose File → Export To → PDF or Markdown. That's macOS 27; on macOS 26 the menu is File → Export as. Apple documents this for one note. Several independent guides report that selecting many notes exports them all as Markdown, which Apple doesn't mention. To keep folders and dates across a whole library, use Obsidian's Importer or the free Exporter app.

I make Cyanote, a notes app that can import some of what this produces, so there's a short section on that near the end. This is a reading of documentation and other people's published tests, checked on 23 November 2026. I haven't run these exports myself.

The short version

  • One note: File → Export To (macOS 27) or File → Export as (macOS 26), then PDF or Markdown. macOS 15 and earlier offer PDF only.
  • Many notes: on macOS 26 and 27, select them in the list first and use the same menu. Reported to work, not documented, so check the result.
  • Obsidian: use its official Importer plugin, not a Markdown export.
  • Word: paste into TextEdit and save as Microsoft Word, or go through Pages.
  • Google Keep: I found no documented import. Paste the text.
  • Locked notes: remove the lock first. Obsidian's Importer skips them, and Notes won't export one as PDF while it's locked, by one macOS 15 report.

So on macOS 15 or earlier, the built-in app exports one note at a time. On macOS 26 and 27, selecting several works according to three independent guides, one of them tested on 27. I found no Apple page that says so, and there's no "export everything" command in its guide.

It isn't always clean either. In a MacRumors thread started in October 2025, one person exporting over 100 notes on iPadOS 26.0.1 got blank files and repeated lines. Another, on macOS 26.2, reported repeated lines across a big export and notes with the same title overwriting each other. These are unconfirmed forum reports, and later updates may have fixed them. They're reason enough to export in small batches and check.

Export one note or many from the Mac app

  1. Open Notes and select the note. For many, click a folder, click any note in the list, and press ⌘ + A.
  2. Choose File → Export To → Markdown (Export as on macOS 26). For a PDF, choose PDF.
  3. Pick a folder and save.

With Markdown, each export reportedly lands in a new folder, named after the note, or "Archive" if there were several. Images and other files go in an Attachments folder beside the text; MacStories found the same for images. Because the Notes folder structure isn't kept, do one folder at a time and rename each "Archive" as you go.

To check it worked, turn on View → Show Note Count in Notes, which shows the number beside each folder. Compare that with the number of .md files. Then open your longest note, one with a table, and one with images. Don't delete anything from Notes until every check passes: one report above had same-titled notes overwriting each other.

PDF has a catch. Apple's iPhone guide says a note holding a multipage PDF or scan exports only the first page of it. The Mac guide doesn't say either way, so check before trusting a PDF of a scanned contract. You can also use File → Print, then save as PDF.

Other ways out for a few notes

Copy as Markdown. macOS 27 adds Edit → Copy as Markdown for selected text. Six Colors reports that images aren't copied.

TextEdit. Select the note's contents, copy, and paste into a TextEdit document. TextEdit can save rich text, plain text, HTML and Microsoft Word formats, which makes it the plainest route to Word. What survives the paste isn't documented.

Pages. Apple's macOS 15 guide describes File → Open in Pages, keeping bullets, indentation and bold. The macOS 27 guide no longer covers it, but La De Du's September 2026 page still mentions Pages as an option. From there, Pages exports to Word. Per the iPhone guide, you can't edit drawings in Pages, scans become thumbnails, and checklists, tags and note links stop being active.

Send a Copy. The share button's Send a Copy puts a formatted note into Mail or Messages, or AirDrops it to someone's Notes. A locked note sent while unlocked can be read without a password.

Tools that take the whole library

Obsidian Importer. Obsidian's help says its official plugin covers "virtually all Apple Notes content types", including tables, images, drawings, scans and PDFs. It's Mac only. Install Importer under Settings → Community Plugins, choose Apple Notes, select Import, and allow access to the group.com.apple.notes folder when asked. You then review a preview and import. Locked notes are skipped. The result is a folder of Markdown files, so it's useful even if you don't stay with Obsidian. I wrote about when Obsidian stops suiting people.

Exporter. The Mac App Store listing says it writes Markdown or HTML, keeps creation and modification dates, files notes in folders named after the originals, and exports all attachments. It's free, with a Notebook Filter and Scheduled Backups at $4.99 each. Version 5.0.1 is dated 20 November 2026.

Apple Notes Exporter, a different, open-source app, writes many more formats, including Word, PDF, EPUB and Evernote's ENEX. That makes it the one I'd look at for Word in bulk. It needs Full Disk Access and covers iCloud and On My Mac accounts only.

AppleScript. You can read Notes' scripting dictionary in Script Editor. On macOS 27.2 it gives a script each note's folder, dates, plain text, attachments and its body as HTML, and says whether it's password protected. There's no Markdown property and no export command, so you'd write the files yourself. For Shortcuts, I found no export action among those Notes declares on macOS 27.2. You'd combine a note's text with a general action such as Make Markdown from Rich Text. With free tools available, I'd script this only for something unusual.

For locked notes, use Remove Lock on each one before exporting. The exported file isn't protected, and neither is the note until you lock it again. Whatever the route, the fifteen-minute test tells you more than a table can.

Apple's own data copy

Where Apple offers it, you can request your iCloud data at privacy.apple.com, and Apple lists notes among what's included. Treat it as a last resort. Apple says content arrives in its original format or an industry-standard one, then names formats for contacts, calendars, bookmarks and mail but not for notes. Anything end-to-end encrypted that Apple can't decrypt is left out, which covers locked notes. If iCloud web access is off, notes don't appear in the list. With Advanced Data Protection on, Apple can't provide end-to-end encrypted data even after you turn web access back on. You get 14 days to download once it's ready.

Into Google Docs, Google Keep or Windows

Google Docs can import a Markdown file, and since October 2026 it can open and edit one directly.

Google Keep has a help page for exporting; I couldn't find one for importing. Paste the text, or open it in Google Docs, select it, and right-click → Save to Keep.

A Windows PC has no Notes app to export from, but iCloud.com shows your notes.

Questions people ask

How do I export Apple Notes from an iPhone?

Open the note, tap the share button, then Export as Markdown. For a PDF, tap Markup and save. Both are in Apple's iPhone guide. Bear's page says iOS exports one note at a time.

Does exporting delete my notes?

No. Exporting makes a copy, and nothing in Apple's steps removes the original. That copy is also your best protection if a note is deleted later.

Should I choose PDF or Markdown?

PDF if you want a record of how the note looked. Markdown if another app has to read it. I compare Markdown and rich text separately.
